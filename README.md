# Russian Roulette Simulator

A browser-based Russian Roulette simulator built with **HTML, CSS, and JavaScript**. It features a simple interactive game interface, player controls, and visual feedback.

## ✨ Features

- Insert a bullet into the revolver
- Spin the chamber
- Pull the trigger
- Add and remove players
- Track the current game status
- Visual muzzle-flash effect
- Clean, minimalist interface
- Fully playable directly in the browser

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- SVG
